- **[nexus](https://github.com/Thyfwx/nexus)**: AI terminal with 4 chat modes, browser games, image generation, leaderboards, and live diagnostics. Cloudflare Workers and Pages, vanilla JS, no framework.
- **[thyfwxit](https://github.com/Thyfwx/thyfwxit)**: the portfolio itself. Hand coded, no templates.
- **[TokIntel](https://github.com/Thyfwx/TokIntel)**: find when a TikTok account was created. No API key, no signup, just a username.
- **[Media-Organizer-Mac](https://github.com/Thyfwx/Media-Organizer-Mac)**: smart file renamer for macOS that reads what's in the file and names it like a human would.
